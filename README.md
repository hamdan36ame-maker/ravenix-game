# RAVENIX - MHP Gaming Division

🎮 **Fast-paced arcade game built with vanilla JavaScript and HTML5 Canvas**

## Features
- ⚡ Real-time player movement
- 👾 Enemy AI with collision detection
- 💥 Attack system with particle effects
- 🎯 Score tracking and level progression
- 📱 Fully responsive - works on mobile & desktop
- 🌟 Beautiful gradient backgrounds with animated stars

## How to Play
1. Click **START GAME**
2. **Move**: Use arrow keys or WASD
3. **Attack**: Press SPACE or click the ⚡ button
4. **Survive**: Avoid enemies and get the highest score!
5. **Win**: Defeat more enemies to level up!

## Game Mechanics
- Each enemy defeated = 100 points
- Enemies get faster every level
- Health decreases when enemies touch you
- Game ends when health reaches 0
- 60 seconds per round

## Controls
- **Arrow Keys / WASD** - Move
- **SPACE** - Attack
- **Mouse Buttons** - On-screen controls (mobile)
- **✕ Button** - Exit game
